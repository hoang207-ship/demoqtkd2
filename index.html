💡 Vì Sao Streamlit Báo Lỗi 404 Trên Vercel & Cách Deploy Chuẩn 1-Click

Streamlit là ứng dụng Python server stateful duy trì kết nối WebSocket thời gian thực (/_stcore/stream). Vercel là nền tảng Serverless tĩnh chỉ chạy API ngắn hạn. Nền tảng chính thức, miễn phí 100% được khuyên dùng là Streamlit Community Cloud:

  1. Bước 1: Đăng nhập vào share.streamlit.io bằng tài khoản GitHub hoang207-ship.
  2. Bước 2: Bấm Create app (hoặc New app), chọn Repository hoang207-ship/demoqtkd2.
  3. Bước 3: Tại ô Main file path, nhập: app.py.
  4. Bước 4: Bấm Deploy! — Trong vòng 1 phút, ứng dụng sẽ có link online vĩnh viễn (ví dụ: https://demoqtkd2.streamlit.app) đầy đủ WebSocket, nạp Google Sheets và chạy 6 bước mượt mà!
